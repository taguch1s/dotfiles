# グローバル作業規約

## ユーザー指定の除外対象

- ユーザーが除外を指定したプロジェクトと関連する過去ログ・memoryを読まず、検索せず、参照せず、外部へ送信しない。作業に必要なら停止してユーザーに確認する。

## 共通の作業規約

- 変更前に、対象アプリケーション、Git リポジトリ、作業ディレクトリ、既存状態を実データで確認する。名称が曖昧で結果が変わる場合だけ、変更せず質問する。
- 恒久的な作業規約はこのファイルまたはリポジトリ管理された文書に置く。Memory と会話履歴は補助情報であり、規約の正本にしない。
- 変更・実装では、対象リポジトリの `CLAUDE.md` / `AGENTS.md`、検証コマンド、Git 状態を確認し、未検証の結果を完了と報告しない。
- 別 task の変更やユーザー所有の未追跡ファイルを、明示指示なしに編集、移動、削除しない。

## Codex と共有する skill

- `~/.claude/skills` の skill は Codex と同じ source を共有する。本文中の `$<skill-name>` は `/<skill-name>` と読み替える。
- skill や文書が `AGENTS.md` を参照する場合、リポジトリに `AGENTS.md` があればそれを正本として読む。
