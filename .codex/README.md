# Codex settings

`config.toml` contains only portable, non-secret user defaults.

Do not version these local files:

- `auth.json` and every token or API key
- `hooks.json`, `herdr-agent-state.sh`, and `[hooks.state]` entries generated by Herdr/Codex
- sessions, logs, SQLite databases, caches, and trusted-project paths

After linking this directory on a new machine, run `codex login`, then install the
Herdr integration with `herdr integration install codex` (the bootstrap target does
this automatically when both commands are available).

The optional Google Search Console MCP setup is intentionally not included because
it needs a machine-local service-account key. Add it manually to `~/.codex/config.toml`
after storing that key outside this repository.
